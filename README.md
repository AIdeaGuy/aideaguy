# AIdeaGuy.dev

Short, practical ways to use AI to get things done. A free, static, mobile-first site: answer three questions, get tips and a prompt to paste into any AI, and make a to-do card. Nothing leaves your device unless you add a sign-up form.

- Plain HTML, CSS and JavaScript. No build step, no dependencies.
- `links.json` holds the optional TikTok, LinkedIn and sign-up form URLs (https only; empty means off).
- `vercel.json` sets the security headers.
- `wordmark.html` previews the animated logo.

Run locally: `npx serve .`
